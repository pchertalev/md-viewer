# Просмотрщик markdown: проверка возможностей

Документ собран, чтобы прогнать по экрану всё, что умеет рендер: таблицы, код, списки задач,
сноски, картинки и ссылки. Файл лежит в `samples/`, картинки — в `samples/assets/`.

## Текст

**Жирный**, *курсив*, ~~зачёркнутый~~, `код в строке`, <u>подчёркнутый</u>.

> Цитата в несколько строк: её тоже надо видеть аккуратно оформленной,
> особенно когда внутри есть `код` или [ссылка](https://example.com).

- обычный пункт;
- пункт с `кодом` и **жирным**;
  - вложенный пункт;
- [ссылка на соседний файл](second.md) — открывается этим же приложением;
- [внешняя ссылка](https://commonmark.org) — уходит в браузер;
- автоccылка: https://github.com/vladsch/flexmark
- якорь внутри страницы: [про таблицы](#таблицы)

## Код

```kotlin
data class Document(val path: Path, val title: String)

fun load(path: Path): Document =
    Document(path, readTitle(Files.readString(path, UTF_8)))
```

```bash
gradlew run --args="samples/demo.md"
```

## Таблицы

| Возможность | Как сделано | Комментарий |
|---|---|---|
| Разбор | flexmark, расширения GFM | таблицы, задачи, сноски[^1] |
| Оглавление | свой обход заголовков | уровни могут прыгать |
| Картинки | `file://` от папки файла | относительные пути работают |

[^1]: Сноска — расширение flexmark, её тоже надо отрисовать.
